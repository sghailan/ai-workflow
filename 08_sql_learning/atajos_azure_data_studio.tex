AZURE DATA STUDIO — ATAJOS IMPORTANTES

EJECUTAR
---------
F5                 Ejecutar query
Ctrl + N           Nueva query
Ctrl + S           Guardar script

EDICIÓN
--------
Ctrl + F           Buscar
Ctrl + H           Reemplazar
Ctrl + G           Ir a línea

Ctrl + K, Ctrl + C     Comentar
Ctrl + K, Ctrl + U     Descomentar

Alt + ↑ / ↓        Mover línea
Shift + Alt + ↓    Duplicar línea

MULTICURSOR
------------
Alt + Click        Multi cursor
Ctrl + D           Seleccionar siguiente coincidencia

NAVEGACIÓN
-----------
Ctrl + Tab         Cambiar pestaña
Ctrl + Shift + E   Explorador lateral
Ctrl + `           Terminal integrada
Ctrl + Shift + P   Command Palette

RESULTADOS
-----------
Ctrl + R           Mostrar/ocultar resultados
